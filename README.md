# 連展電能 充電站巡檢（手機版）

手機優先的充電站巡檢 App，純前端靜態網頁，部署在 GitHub Pages。可加入手機主畫面，離線也能用。

## 功能

- **站點管理**：新增、編輯、刪除、搜尋。站點資料包含地址、電力容量、設備規格、纜線規格
- **巡檢表**：17 項預設檢查項目，每項可點選 O 正常 / X 異常 / — 不適用，並填寫數值與備註
  - 一鍵把未檢項目設為正常
  - 標成異常時自動展開紀錄欄位；儲存時提醒未填說明的異常
  - 進度條顯示已檢項目數與異常數
  - 每次巡檢都另存一筆，保留歷史紀錄
  - 填寫中自動存草稿，誤關頁面也不會遺失
- **現場照片**：可直接拍照或從相簿選取，自動壓縮到 200KB 以內，每張可加說明
- **巡檢項目設定**：新增、刪除、排序，只影響之後的新巡檢
- **匯出**（手機上會開啟系統分享，可直接傳到 LINE 或存到檔案）
  - 單站 Excel：每次巡檢一個工作表（含站點資料與照片）、歷次狀態對照
  - 全站 Excel：站點總覽、待改善異常、全部明細；可選擇附上每站最近一次巡檢與照片
  - 全站壓縮檔 ZIP：每站一個 Excel（含照片）＋全站總表
  - 相簿 ZIP：依巡檢日期分資料夾
  - JSON 完整備份（含照片），可還原或搬到另一支手機

## 資料存放

所有資料都存在**手機瀏覽器的 IndexedDB**，不會上傳到任何伺服器。

- 不同手機、不同瀏覽器之間**不會自動同步**；換機或清除瀏覽器資料前，請先從選單「下載備份」
- 建議加入主畫面使用（iOS Safari：分享 → 加入主畫面；Android Chrome：選單 → 安裝應用程式），比較不會被系統清掉資料

## 本機開發

```bash
python3 -m http.server 8000
# 開啟 http://localhost:8000
```

沒有建置流程，直接改 `index.html`、`css/`、`js/` 即可。

| 檔案 | 說明 |
| --- | --- |
| `js/store.js` | IndexedDB 存取、預設巡檢項目、備份與還原 |
| `js/app.js` | 畫面與操作邏輯（hash 路由） |
| `js/export.js` | Excel / ZIP / JSON 匯出 |
| `sw.js` | 離線快取 |
| `vendor/` | ExcelJS 4.4.0、JSZip 3.10.1 |

**更新程式後**，請把 `sw.js` 裡的 `CACHE` 版本號加一（例如 `acon-inspection-v2`），手機才會抓到新版。

## 部署

推到 `main` 分支後，GitHub Pages 會自動發佈（Settings → Pages → Branch: `main` / root）。
